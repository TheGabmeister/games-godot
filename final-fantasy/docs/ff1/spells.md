# Final Fantasy I Pixel Remaster — Spells

Complete spell list (64 spells: 32 White Magic, 32 Black Magic). Classes use abbreviations: Kn=Knight, Ni=Ninja, RM=Red Mage, RW=Red Wizard, WM=White Mage, WW=White Wizard, BM=Black Mage, BW=Black Wizard.

Each class can learn **3 spells per spell level** (shops sell 4 per level).
